# Fizzy downloads

Fizzy connects ChatGPT to the user's own Mac for coding, Chrome tasks and built-in Computer Use. Published by Asymmetry-lab / Anunda Boonserm.

Setup: https://fizzy-public.asymmetry-lab.com/setup

These are versioned preview downloads for public-release preparation. The OpenAI Public listing has not been submitted or published. The Mac app requires macOS 14 or newer and is ad-hoc signed, not Apple notarized. Apple Silicon runtime checks have passed; physical Intel and fresh-Mac launch/permission checks remain unverified.

Install the Mac app with the single command on the setup website, add the Chrome companion, then connect your own Fizzy account and computer. Fizzy accounts are independent of KhaiHub. Keep the Mac online while working. ChatGPT supplies reasoning; the local app executes tools. Files, commands and computer actions can change data or interact with services you are signed into.

This repository hosts download artifacts. It does not host user accounts, connection credentials or the publisher's private repository.
